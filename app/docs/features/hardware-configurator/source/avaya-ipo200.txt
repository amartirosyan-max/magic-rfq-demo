Hyper-V cluster summary 
Overall, the proposed system provides 896 physical CPU cor	es configured from the entire cluster. 832 physical cores available when one node failure is considered from the entire cluster. We have designed 1:1 and 1:2 physical-to-virtual ratio based on detail sheet given by the Avaya team. From the RAM perspective, it has configured 1.8TB RAM from the entire cluster and 1.6TB RAM can use one node failure situation.  According to the given requirement, the system is designed to have CPU and memory to withstand single-node failure without any performance degradation.
The Virtualization solution is the basement of the 14 node High Availability Cluster Solution. Windows server 2022 will install on physical hosts and deploying Hyper-V HA cluster using Dell EMC Unity 380XT SAN Storage connecting via brocade SAN switches.
All servers are designed with 2x dual-port 32 Gbps Fiber channel HBA cards that facilitate SAN Storage connectivity and Dual port 25G Data traffic connecting through the S5224 ToR Switches. 
VMware cluster summary 
Overall, the proposed system provides 192 physical CPU cores configured from the entire cluster. 96 physical cores available when one node failure is considered from the entire cluster. We have designed 1:1 and 1:2 physical-to-virtual ratio based on detail sheet given by the Avaya team. From the RAM perspective, it has configured 512GB RAM from the entire cluster and 256GB RAM can use one node failure situation.  According to the given requirement, the system is designed to have CPU and memory to withstand single-node failure without any performance degradation.
The Virtualization solution is the basement of the Three node High Availability Cluster Solution. VMware ESXi hypervisor will install on physical hosts and deploying VMware HA cluster with the Dell Unity 380XT SAN Storage. To centrally manage the cluster and entire virtual infrastructure VMware vCenter server will host inside VMware HA Cluster as a Virtual Machine. High availability and all other advanced features can be configured using the vCenter virtual appliance. 
All servers are designed with 2x dual-port 32 Gbps Fiber channel HBA cards that facilitate SAN Storage connectivity and VMware Data traffic connecting through the customer given ToR Switches. 


Storage summary
The proposed storage consists of 14 x 3.84 TB SSD drives, and we have considered two main Clusters to meet the capacity requirements in the Avaya. 
Unity XT HFAs enable IT to cost effectively consolidate and manage traditional file and transactional workloads with several VMware and Microsoft virtualization integrations – to meet the economics, scale, performance and data protection needs of the data center.
From a performance perspective, Unity 380XT can deliver 65000 IOPS at 2ms latency to meet the performance requirements. Furthermore, the Unity 380XT provides Unified architecture, and the entire appliance has 128GB of cache memory, which helps deliver fast I/O response for applications, enhancing the performance of the designed solution. Moreover, Unity 380XT operates with active-active FC controller connectivity, ensuring hardware availability in the storage system.
Furthermore, Unity 380XT storage and hosts servers will connect the 24 port 16G FC SAN switches to delivers more performance and availability.

Dell EMC PowerSwitch S5200-ON Series
The PowerSwitch S5200-ON 25/100GbE fixed switches comprise Dell Technologies’ latest disaggregated hardware and software data center networking solutions, providing state-of-the-art, high-density 25/100GbE ports and a broad range of functionality to meet the growing demands of today’s data center environment. These innovative, next-generation open networking switches offer optimum flexibility and cost-effectiveness for web 2.0, enterprise and cloud service providers with demanding compute and storage traffic environments.
The S5200-ON is a complete family of switches:12-port, 24-port, and 48-port 25GbE/100GbE ToR switches, 96-port 25GbE/100GbE Middle of Row (MoR)/End of Row (EoR) switch, and a 32-port 100GbE Multi-Rate Spine/Leaf switch. From the compact half-rack width S5212FON providing an ideal form factor for hyper-converged deployments, to the high density S5296F-ON for Middle of Row deployments, the S5200-ON series offers performance and flexibility for a variety of network designs.
In addition to 100GbE Spine/Leaf deployments, the S5232F-ON can also be used in high density deployments using breakout cables to achieve up to 128 10GbE or 128 25GbE ports.
Using industry-leading hardware and a choice of Dell EMC SmartFabric OS10 or select 3rd party network operating systems and tools, the S5200-ON switches incorporate multiple architectural features that optimize data center network flexibility, efficiency and availability, including IO panel to PSU or PSU to IO panel airflow for hot/cold aisle environments, redundant, hot-swappable power supplies and fans and deliver non-blocking performance for workloads sensitive to packet loss.
Priority-based flow control (PFC), data center bridge exchange (DCBX) and enhanced transmission selection (ETS) make the S5200-ON family ideally suited for DCB environments.
Dell EMC PowerSwitch S5200-ON switches support the open source Open Network Install Environment (ONIE) for zero touch installation of Dell EMC SmartFabric OS10 networking operating system, as well as alternative network operating systems.
